# LidAwake

Мини-приложение для строки меню macOS: позволяет оставить мак работать с закрытой крышкой и вернуть обычный сон одним кликом.

- Клик по иконке — переключить режим (`pmset -a disablesleep 1/0`, спросит пароль администратора)
- Правый клик / ⌥+клик — меню: переключить, погасить экран, выход
- ☕ — сон отключён, 🌙 — обычный режим

## Сборка

```bash
./build.sh
open LidAwake.app
```

Нужны только Command Line Tools (swiftc). Настройка `disablesleep` сохраняется после выхода из приложения и перезагрузки — выключайте её кнопкой.
